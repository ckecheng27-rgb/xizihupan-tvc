# 我在西子湖畔 · TVC创意与AI实践方案

> 全屏滚动式交互展示网页，将《"我在西子湖畔"直播间TVC创意与AI实践方案》PPT转为沉浸式Web体验。

## 技术栈

- 纯前端 HTML + CSS + JavaScript
- CSS `scroll-snap` 实现全屏滚动
- 视频背景（FFmpeg压缩至720p）
- GitHub Pages 静态托管

## 本地预览

用浏览器直接打开 `index.html` 即可。
